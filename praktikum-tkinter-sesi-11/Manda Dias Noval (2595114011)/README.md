## Tujuan
Membangun aplikasi GUI pendaftaran kegiatan mahasiswa menggunakan Python Tkinter dengan berbagai widget, event handling, validasi input, menu, dan dialog.

## Fitur
- Entry untuk memasukkan nama lengkap.
- Combobox untuk memilih program studi.
- Radiobutton untuk memilih jenis kelamin.
- Checkbutton untuk memilih satu atau beberapa kegiatan.
- Text untuk mengisi alasan mengikuti kegiatan.
- Tombol Submit untuk memproses pendaftaran dan menampilkan ringkasan.
- Tombol Reset untuk mengosongkan formulir dan hasil.
- Listbox untuk menampilkan kegiatan yang dipilih.
- Validasi agar nama tidak boleh kosong dan minimal satu kegiatan harus dipilih.
- Messagebox untuk notifikasi dan konfirmasi keluar.
- Menu File > Keluar.
- Menu Bantuan > About yang membuka jendela Toplevel.
- Tombol Enter dapat digunakan untuk menjalankan Submit.

## Cara Menjalankan
1. Pastikan Python 3 sudah terpasang.
2. Pastikan Tkinter tersedia (biasanya sudah termasuk dalam instalasi Python).
3. Buka terminal/CMD pada folder proyek.
4. Jalankan perintah:

   ```bash
   python main.py
   ```

5. Isi formulir, pilih kegiatan, lalu tekan tombol Submit atau tombol Enter.
